# Hassana's Magical Paws

A self-contained Arabic interactive browser game featuring Hassana, Shadow, Loly, and Desha.

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create or open a GitHub repository.
2. Upload the contents of this ZIP to the repository root. Make sure `index.html` is directly in the root, not inside a folder.
3. Commit the changes.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/(root)`, then save.
7. Wait for deployment, then open the URL shown in Settings → Pages.

No build step or external libraries are required.
